# 老街记忆店

给 65 岁以上长辈训练记忆力的手机网页游戏。玩家是怀旧杂货店老板，听客人说要买什么，记住后从货架拿货结账。

单一文件 `index.html`（HTML + CSS + JavaScript），不需要后端，用手机浏览器打开就能玩。

## 玩法
- 每局 5 位客人，客人用对话框和普通话语音说出要买的东西。
- 客人说完，清单收起；点货架商品、选数量，再按「结账」。
- 全对得到「人情分」；答错客人会温和提示，可以再试，不扣分。
- 难度自动调整（共 9 级）：连续 3 位一次答对升一级，连续答错 2 次降一级。
- 没有计时，可随时按「再听一次」。

## 趣味设计
- 连续一次答对有「连对」奖励分。
- 结账时金币、爱心飞出，客人还会聊一句怀旧家常。
- 累计人情分解锁 10 件小店装饰（红灯笼、小花猫、老收音机……）。
- 首页有本周开店印章。

## 进阶关卡（升到第 5 级解锁）
- 客人改口：「酱油不要了，换成两包糖。」
- 两位客人同时点单，要分开两个篮子拿（第 6 级起）。
- 熟客：头上有 ⭐ 的客人会先说「记住我买的东西」，隔一位客人后回来说「跟上次一样」。答错两次会把上次的单子再说一遍。

## 资料
用 `localStorage` 记录难度、每天最高难度、人情分和装饰，首页显示「已连续开店 X 天」。所有资料只留在该部手机的浏览器。

## 试玩
- 直接用浏览器打开 `index.html`；或
- 开启 GitHub Pages（Settings → Pages → Deploy from a branch → main / root），用网址在手机上玩。
