# 老街記憶店

給 65 歲以上長輩訓練記憶力的手機網頁遊戲。玩家是懷舊雜貨店老闆，聽客人說要買甚麼，記住後從貨架拿貨結帳。

單一檔案 `index.html`（HTML + CSS + JavaScript），不需要後端，用手機瀏覽器打開就能玩。

## 玩法
- 每局 5 位客人，客人用對話框和語音（粵語／國語可切換）說出要買的東西。
- 客人說完，清單收起；點貨架商品、選數量，再按「結帳」。
- 全對得到「人情分」；答錯客人會溫和提示，可以再試，不扣分。
- 難度自動調整（共 9 級）：連續 3 位一次答對升一級，連續答錯 2 次降一級。
- 沒有計時，可隨時按「再聽一次」。

## 進階關卡（升到第 5 級解鎖）
- 客人改口：「醬油唔要喇，換兩包糖啦。」
- 兩位客人同時點單，要分開兩個籃子拿（第 6 級起）。
- 熟客回來說「同上次一樣」。

## 資料
用 `localStorage` 記錄難度、每天最高難度和人情分，首頁顯示「已連續開店 X 天」。所有資料只留在該部手機的瀏覽器。

## 試玩
- 直接用瀏覽器打開 `index.html`；或
- 在 GitHub 的 Settings → Pages 開啟 GitHub Pages，就可以用網址在手機上玩。

粵語語音需要手機內建粵語聲音（iPhone 一般有；部分 Android 沒有，會改用其他中文聲音）。
